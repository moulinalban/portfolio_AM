## 1. Cadrage général

### 1.1 Objet du document
Le présent document formalise le besoin, le périmètre, les contenus, les contraintes techniques, les exigences de design et les critères de validation du portfolio web d'Alban Moulin.

Il sert de base de référence pour :
- la conception et la structure du site ;
- le design et l'identité visuelle ;
- l'intégration des contenus ;
- les tests et la validation finale ;
- les futures évolutions.

### 1.2 Présentation du projet
Le portfolio est un site web personnel destiné à valoriser le parcours, les compétences et les réalisations d'Alban Moulin, Chargé de Communication & Marketing.

Il doit permettre à tout visiteur de comprendre rapidement le profil d'Alban, de consulter ses réalisations par expérience professionnelle, de télécharger son CV et de le contacter directement.

### 1.3 Contexte
Alban Moulin est actuellement en poste chez Bricolagedirect.com (Unipro Group) en CDI depuis novembre 2025. Il souhaite se constituer un portfolio web professionnel pour accompagner sa recherche d'opportunités dans la communication et le marketing, notamment vers des postes de Chargé de Communication dans la région Lyon / Saint-Étienne.

Il dispose de réalisations concrètes et de chiffres de performance solides à valoriser sur quatre expériences professionnelles.

### 1.4 Objectifs du projet
Le portfolio doit permettre :
- de présenter le profil et les compétences d'Alban de manière claire et impactante ;
- de valoriser ses réalisations avec des visuels, vidéos et chiffres de performance ;
- de permettre aux visiteurs de télécharger son CV ;
- de permettre aux visiteurs de le contacter directement ;
- de renvoyer vers son profil LinkedIn ;
- d'être mis à jour et enrichi de nouveaux projets facilement et en autonomie.

### 1.5 Cibles
Le portfolio s'adresse à trois profils de visiteurs :
- recruteurs RH ;
- directeurs Marketing / Communication ;
- agences de communication.

### 1.6 Actions attendues
Les actions principales attendues sont :
- consulter les réalisations ;
- télécharger le CV ;
- contacter Alban via le formulaire de contact ;
- accéder à son profil LinkedIn.

## 3. Design

### 3.1 Identité visuelle
- Couleurs principales : Noir / Bleu (cohérence avec le CV actuel)
- Ambiance : créative et originale
- Typographie : grande et impactante

### 3.2 Références visuelles
Les références suivantes ont été validées comme sources d'inspiration :
- **Adam Zonski** — fond sombre, typographie grande, photo personnelle mise en valeur, chiffres clés visibles
- **Duwy** — mise en page aérée, espace blanc, chiffres impactants
- **Mirko Romanelli** — typographie XXL, minimalisme, navigation épurée
- **LucaDCZ** — photo personnelle en avant, navigation simple, appels à l'action clairs

### 3.3 Principes de design
- Dark mode privilégié
- Typographie grande et lisible
- Photo personnelle professionnelle bien mise en valeur
- Beaucoup d'espace blanc / aération
- Chiffres clés visuellement mis en avant
- Navigation simple et minimaliste
- Responsive mobile obligatoire

## 5. Critères de validation

### 5.1 Délai
Le site doit être en ligne dans moins d'un mois.

### 5.2 Critères de validation fonctionnels
Le portfolio sera considéré comme conforme si :
- toutes les pages sont accessibles et fonctionnelles
- les 4 blocs de résultats clés sont visibles sur la page d'accueil dans le bon ordre
- chaque expérience dispose de sa propre page dédiée
- les expériences sont présentées dans l'ordre chronologique décroissant
- le CV est téléchargeable en PDF
- le formulaire de contact est opérationnel
- le lien LinkedIn est fonctionnel
- les visuels et vidéos se chargent correctement
- le site est consultable et exploitable sur mobile
- l'ajout d'un nouveau projet est réalisable en autonomie

### 5.3 Éléments à finaliser avant lancement
